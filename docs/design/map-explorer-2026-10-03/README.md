# 连续地图探索 · 设计与验收

2026-10-03。用户批准递进地图导航并要求维持整站美术语言。此文描述可用边界内的交互，不宣称全球市区、道路或地铁覆盖。

## 设计选择

地图内路径代替页面顶部的地图下拉；返回上一级、搜索已支持地区，地图选项保留照片模式 / 常用地区 / 导出 / 管理。地图点击与滚轮 / 按钮在同一坐标空间下工作，用户不会因进入城市失去拖拽能力。层级进入 / 退出使用不同阈值，避免临界尺度来回闪切；路径变化不重设相机。显式导航 360ms 平滑聚焦，直接手势中断动画，减少动态效果时直接定位。

日本国家 → 都道府县 → 市区町村，中国 → 四川市州 → 成都区县；世界 / 亚洲 / 国家用于退出和更大范围探索。只在有实际数据的地方细化。日本带远端离岛的市，默认聚焦最大连续陆块，所有离岛轮廓仍保留，可拖拽 / 缩小查看。亚洲是视窗，不是新行政边界。

主标题、宋体 / 系统控件字体、暖纸 / 深墨 / 朱红和统一光源沿用已认可界面。地图的行政线是信息图形；控件和浮层常态由光影建立边界。操作 44px，手机路径只保留近两级，320px 只显示当前层和返回；地图选项折叠为小图标，图例在有浮动记录卡时收起以免遮挡。保留键盘焦点、高对比和减少动态效果。

## 修正记录

- 首次 ResizeObserver 测量中断导航动画、路径与取景不一致：尺寸变化时完成目标定位，普通尺寸变化保留相对缩放。
- 日本原标签误用郡名，932 个町村出现重复：同一固定上游源修正 N03_004，源 ID / 几何逐项保持不变；搜索索引同步重建。
- 拼图点击仅按地区名可能误选同名市村：携带 source feature ID 和所属县；无坐标同名记录保留在父级，不染色或出现在任意子区域。
- 同县一条到访不能染色所有城市：节点按保存的地区字段 / 确认坐标筛选；手动保存的历史深度只作用于其明确地区。
- 相机每帧重复计算路径 / 照片拼图：缓存路径和地区记录，尺度未过笔记阈值时不重建照片内容。
- 手机展开记录与地图图例重叠：选中后自动收起抽屉，有浮动记录入口时隐藏图例。

## 实际验收

96 项合成测试、typecheck 和正式 production build 通过；隔离 QA 路由 / 接口已移除，构建路由清单没有测试入口。测试涵盖层级数量 / 路径、搜索、相机有限值、缩放锚点、进出阈值、国家 / 省 / 市 / 区筛选、同名记录保护、主城区取景，并继续覆盖 EXIF 缺失 / 异常、确认、元数据剥离、权限和失败重试。所有测试到访是明确标注的隔离合成记录，不写私有日志。

浏览器：320×720、390×844、768×1024、1280×720，深浅两主题。实际操作了世界照片轮廓点击进入日本、日本 → 福冈县 → 福冈市、四川 → 成都 → 锦江区，连续缩小市 → 县 → 国家 → 亚洲 → 世界、原生拖拽与滚轮、地区搜索、键盘 Enter、手机记录抽屉和时间线定位。最窄尺寸与平板 document.scrollWidth 等于 viewport 宽；新会话控制台无 error / warn。双指使用 pointer capture / 锚点算法，数学测试通过，未以此代替物理设备测试。

照片模式：已保存到访关联照片，单张 cover 且不重复，城市轮廓裁切。福冈手填笔记在细节尺度有 data-photo-note；鹿儿岛无笔记不添加；span 超过 8 后关闭笔记提示。切换尺度和拖拽仍可用。导出继续按既有五种作品范围，三种模板和自定义不变。先使用 PNG 合成素材时导出按原 JPEG 契约阻止，换为正确 JPEG 合成接口后读取 / 预览 / 下载按钮正常；未放宽生产媒体校验。
