# 旅行时间线 · 2026-10-03

将旅行记录按时间阅读，保持项目暖纸、深墨、朱红、宋体标题与轻柔光影的视觉语言。独立年月 / 日历日期取代并排卡片；不画装饰时间轴线，日期用浅凹陷标签，记录用浮起表面。

## 已实现

- 按年月 / 日期倒序；同日记录独立显示，跨年月份可跳转。记录条数仅计当前筛选结果。
- 默认所选旅行地图全部地区，主动选择当前地区可进一步过滤；手机筛选按需展开，当前范围仍出现在页头。
- 桌面日期栏 + 图文并排；手机日期标签 + 照片优先；640–800px 平板改为图文并排，避免大封面推走笔记。
- 单照片封面、多照片缩略图；点击具体照片进入同一查看器的相应照片。无照片记录直接阅读文字，缺失笔记不填占位文案。
- 长笔记三行摘要 / 展开 / 收起；标题与“查看地图”先聚焦地图并折叠手机列表。“查看记录”保留详情和低优先级管理入口。
- 控件 hover / pressed 沿用 UI Kit；轻微记录入场、照片 hover、展开图标过渡；遵循减少动态效果与高对比设置。

## 数据约束

日期为用户确认的到访日历日期，不进行时区转换，不使用上传时间补全。只展示 checkins，不把未确认照片草稿加入时间线。日期缺失 / 非法的旧记录归末尾待补充；重复到访、同日多照片记录均保留独立 ID。按日组织只是排版，没有自动旅程合并、路线推断、地点识别或探索深度推断。数据仓库、权限、上传和保存 API 没有改变。
