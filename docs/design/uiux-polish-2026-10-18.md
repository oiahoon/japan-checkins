# UI / UX 打磨 · 2026-10-18

本轮延续暖纸 / 深墨、朱红点睛和左上光源的扁平拟物语言，使用当前应用截图审阅后修改，不另做一套视觉主题。审阅使用临时隔离界面加载真实组件与合成数据；没有读取、修改生产照片或日志，也没有将 QA 路由加入应用。

## 发现与实现

| 当前问题 | 本轮处理 |
| --- | --- |
| 手机照片库标题、管理、搜索、排序和记录筛选堆叠，照片出现太晚 | 390px 将标题与操作合为一排，次要操作用有名称的图标；旅行记录和排序收入可展开筛选。相同合成页面照片网格顶部由约410px降至281px；320px仍允许操作换行，优先保证44px触控面积。 |
| 排序在手机上只有图标，看不到所选内容 | 在展开面板内恢复“排序”标签和完整选项，记录筛选同组；桌面宽屏将搜索和这两项并排对齐。 |
| 收起后容易忘记按哪条旅行记录筛选 | 保留可直接清除的记录标签、筛选数量和“结果 / 全部”计数。长记录名截断但清除按钮保留。 |
| 照片没有选中也显示勾号，选择模式缺少明显退出入口 | 只在选中后显示朱红勾选；选择按钮凹下，选择条提供退出、清空和加入记录。跨筛选选择规则不变。 |
| 时间线所有操作视觉权重相近 | 新建旅行记录使用主按钮，管理收为更多图标；地区筛选开启后保留凹下状态，320px允许操作换行。 |
| 平板照片两列过大 | 640–800px使用三列，手机两列，宽屏继续自适应。 |
| 各区域焦点与滚动手感不统一，照片 / 时间线加载只显示一行文字 | 统一键盘焦点、常规控件触控反馈与弹层滚动边界；保留地图 / 导出拖动区域原有touch-action；加载时使用稳定尺寸的光影占位，减弱动态设置下停止动画。 |

保留地图主视觉、自动折叠地区面板、全屏照片查看器、照片编辑的主次字段、导出预览与设置分层。没有为了覆盖页面而重写已经合理的布局；没有改变EXIF确认、照片归属、删除、认证、只读基础版与服务端进阶版的契约。

## 验收与范围

- 浏览器检查320×740、390×844、768×1024、1280×800，照片库各断点无页面横向溢出；亮 / 暗主题均有截图复核。
- 实际操作：展开 / 收起筛选、按记录筛选与清除、搜索无结果后恢复、进入 / 退出照片选择、照片编辑与放大查看、查看器放大与关闭、时间线切换、地图菜单与导出设置展开。
- 只读角色检查：不显示新增、选择、批量管理和照片关联操作，未标记照片仍打开查看器。
- `npm run typecheck`、`npm run build`、`npm test`（153项）、`npm run build:basic`、静态产物隐私扫描与`git diff --check`。
- 本轮只改界面，不重复执行真实照片写入或生产数据删除。照片写入安全的既有测试仍通过；没有据此宣称重新验收生产主人会话、真实手机软键盘、打印或原生分享。
- 大型基础版分块的构建提示仍存在；占位是感知加载优化，不是网络速度或Core Web Vitals提升的证据。

截图保存在本地临时审阅目录，未将真实照片、凭据、环境文件或QA入口提交到Git。发布证据见PROGRESS与CONTEXT顶端。
