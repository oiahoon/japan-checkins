# 既有照片私有副本与实际弱网验收 · 2026-10-21

## 执行范围与原数据保护

用户明确授权为线上已有照片补齐 ImageKit 私有副本。只处理当前 owner 下 9 张可访问照片，13 张已回收或所属记录回收的照片排除，没有恢复、发布、确认地点或改写记录。展示 JPEG 与缩略图两种版本共 18 份，复用 9 份、新建 9 份，总读取验证字节 6,778,537。

先用非个人合成探针验证全局签名保护，再按源版本和现有生产命名空间逐份补齐。18 份均确认 `isPrivateFile=true`、签名原始字节读取与去元数据源一致，无签名访问均被拒绝（401 / 403）。没有复制 inbox / RAW 原文件，没有发送私人 EXIF、地点或笔记。采用既有 `sanitizeJPEG` / ImageKitDelivery，不重新压缩展示图。

维护工具仅在本机临时目录，Git 传输拒绝所有非 GET 请求。补齐前后与浏览器验收后，数据仓库仍为 private，HEAD 与完整 index.json 字节指纹均保持一致，因此 Git 内的原图、缩略图、记录信息与回收状态没有变化。未把私人图像、索引、ID、SHA、签名链接或凭据放入公开 Git；仅保留本文聚合证据。

这是本实例的一次授权维护，不是产品新增了持久批量补齐队列 / 进度或公共迁移接口。默认按需镜像与新用户默认 Git 的行为不变。

## 正式站回读

已登录主人会话的正式照片库显示 9 张卡片。首屏 4 张均为最长边 768px 的缩略图；其余 5 张离屏时没有 src，未提前抢网。滚动后 7 张累计完成读取，当前可见照片无破图；没有继续遍历全库来充当冷加载测速。正式页未显示框架错误覆盖层，console warn / error 为 0。本轮没有执行保存、删除或上传新记录。

## 受控手机弱网方法

使用当前 Travel、PhotoLoader、统一图片读取器、journalAPI 与 GitHubStore，源为实际私有数据仓库和真实 ImageKit 副本。另建仅监听 127.0.0.1 的密码认证只读中继，所有写入拒绝；不修改生产配置、账户签名限制或真实 CDN 可用性。中继不调度副本修复任务，因为所测版本已经全部补齐；生产 Next after / 冷启动按需补齐不由这次回环覆盖。

390×844 同源 iframe 用于响应式布局，宿主窗口大小变化不影响内框 390px；没有横向溢出。不是实体 iPhone、Safari、移动 CPU 模拟、LCP / INP / FPS 或真实运营商验收。代码、公开地理资料和 JSON 未整体限速；仅照片 payload 共享约 48KiB/s 并增加 400ms 响应延迟。计时从临时应用开始渲染到首张图 load，排除脚本冷下载、登录与合成签名预检，不能称为生产冷启动指标。

为对真实 CDN 与 Git 应用相同限速，验收读取器将合法短期 CDN URL 转入认证的本机中继；仅该本机跳转附带本机 session，向真实 ImageKit 的请求不带站点 Cookie / Git token。账户与命名空间限定，不允许任意外部目标。初始中继未带本机认证的试跑与保护窗口到期的混合读取不作为 CDN 性能数据；稳定对照在独立签名保护窗口内完成。

## 结果

| 场景 | 首张图 | 可见缩略图成功 | Git blob 读取 | CDN 请求 |
| --- | ---: | ---: | ---: | ---: |
| Git 基线，最终同版中继 | 8759ms | 4 / 4 | 4 | 0 |
| 真实 ImageKit | 6433ms | 4 / 4 | 0 | 4，均 200 |
| 本机仅对 CDN 注入 503 | 10673ms | 4 / 4 | 4 | 4，均 503 后回退 |

三组为同样四张照片，完整 payload 合计 377,730 bytes。早期另一次 Git 首图为 6848ms，说明往返、调度和源端波动不可忽略；样本不足，不能推广固定提速比例或运营商收益。可靠结论是：正常加速替代了对应 Git blob 读取，故障时仍能完成读取，画质 / payload 未减少来换速度。

正常 ImageKit 下，前台实际展示图 645,951 bytes 在 15009ms 完整传输，编辑器与自有查看器显示 1600×1200；该段 Git blob 为 0，没有降级成小图、超时或截断。503 故障的浏览器覆盖为缩略图列表，没有声称另外完整重测了大图故障、拼图或导出。用户取消、超时和各版本回退仍由现有自动化补充覆盖。

故障只在本机中继注入，不停用生产 ImageKit、不改真实文件权限、不删除私人副本。失败后照片库没有可见破图、横向溢出或无限等待。临时服务与验收标签页在结束后关闭，失效的本机会话凭据清理；生产继续正常加速。

## 限制与后续

正式站控制台检查通过；临时 Vite / iframe 环境仍出现 MutationObserver.observe 参数不是 Node 的错误，app / lib 中没有相应调用，来源尚未定位，未在正式页观察到。部分定位器操作也超时；以随后 DOM / 实际传输 / 查看器状态确认交互结果，没有将工具动作返回当作成功。本机 console 不计全通过，不因该现象盲目修改生产组件。

真实手机 Safari、丢包 / 切网、长时间滚动、大图库、不同国内线路收益仍需独立验收。此前 PNG 下载历史 Stopped 的问题不在本轮处理范围，不能以照片读取成功宣称导出落盘已修好。所有公开文档仅保留聚合结果，不附私人照片截图或元数据。
