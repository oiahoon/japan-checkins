# ImageKit 可选私有加速验收 · 2026-10-21

## 交付与默认行为

Git 继续为唯一数据源，`PHOTO_DELIVERY=git` 为默认。服务端可选 ImageKit 私有镜像、60 秒签名读取、浏览器失败回退与缺图修复；GitHub Pages 基础版不接入提供商私钥。上传先保存 Git，镜像放在响应后，失败不改变保存结果。配置入口、合成保护检查和关闭步骤见 [IMAGEKIT](../IMAGEKIT.md)。Cloudflare R2 / S3 兼容接口仍为第二阶段计划，没有启用。

本轮没有迁移已有私人照片，没有修改原图、缩略图、EXIF 字段、笔记或旅行记录。账户由用户注册并完成邮箱验证，使用已有密钥，没有生成 / 轮换密钥。配置仅保存在本机被忽略的环境文件中；生产未配置 ImageKit、未开启私人照片副本。

## 真实 ImageKit 服务

只使用隔离合成数据域，与生产数据仓库和 owner 无关。三张 1600×1200 合成 JPEG 及三张 768px 缩略图经过实际 API 上传；35 次请求验证六份文件均能签名读取且字节与上传内容一致，无签名与过期签名均返回 401，跨域允许读取。保护探针使用 8×8 非个人合成色块，验证 unsigned 原图与变换均被拒绝，并尝试清理。未向提供商发送真实私人照片、位置、日期或笔记。

真实服务浏览器回环中，使用实际 Travel UI、JournalTransport、GitHubStore 和 PhotoLoader；Git 端为隔离内存传输，ImageKit 为真实账户。390px 响应式页看到三份 768×576 小图，查看器读取 1600×1200 大图，编辑器保留合成地点 / 日期 / 笔记；期间 Git blob 额外读取为 0。实际网页上传另一张合成 JPEG 成功，保持独立未标记记录，没有自动确认旅行。福冈市两张照片拼图进入导出，作品嵌入两份 JPEG data URL，无外部照片链接。

这个回环没有走生产密码登录，不代替线上真实私仓 / 真机验收。API 测试每项计时包含读取、未签名拒绝和过期拒绝，不能当作单图 CDN 下载速度。

合成文件清理：仅按本轮逐个记录的 11 个 fileId 清理，8 个删除成功、3 个保护探针已不存在，无失败；未遍历或删除账户其他文件。

## 手机与受控弱网

390×844 同源 iframe 验收无横向溢出，覆盖照片库、上传、编辑、查看器、地图城市拼图和作品生成。工具 viewport 设置未改变宿主尺寸，故明确采用响应式 iframe，不能称为 iPhone / Safari 真机。

受控中继仅对照片 payload 施加共享 48KiB/s 和 300ms 响应延迟，使用同一缩略图大小；脚本和公开地理数据没有全局限速。Git 首图 2740ms，模拟 ImageKit 首图 2723ms，差异不足以证明性能提升；三图 payload 约 55.7–56.0KB，相同限速下完成时间接近。它证明统一调度兼容第二读取源和 Git 流量分担，不能代表真实 CDN 在用户线路的收益。真实 ImageKit 浏览器请求没有相同的限速条件，不与这些值作速度比。

CDN 故障、取消、超时和页面退避由自动化合成传输覆盖；真实提供商停服 / 额度耗尽未人为触发。没有保证固定提速比例。

## 导出与保存门槛

导出仍限制两路、100 张、24MiB；本轮单图预算从 15 秒提高至 45 秒，整体从 45 秒提高至 120 秒，避免两张清晰图在弱网共享带宽时被过早中止。超时仍有错误反馈，不静默遗漏照片。

真实 ImageKit 合成图进入作品预览并成功生成 PNG。生成后的本地保存入口改成有图标的 44px 高光影按钮；DOM 检查入口在可视范围内、命中未被遮挡，包含 download 属性。系统分享不可用的回退反馈从“图片已下载”改为“图片已生成”，不把生成等同落盘。

浏览器工具不支持 iframe Blob 下载，并拒绝 Blob URL 导航；未绕过此限制。用户上一版反馈“点不动”，本轮已重开有效作品并请求手动确认。文件实际保存、系统分享与真机手势仍是独立验收门槛，不能以 PNG 生成完成代替。
