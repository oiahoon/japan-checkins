# 地区照片拼图效果预览

2026-10-03，用户要求先随机找照片试效果。本轮是独立本机预览，不接入行程、不向私有数据仓库写入、不提供新的生产路由。

可复用预览：`docs/prototypes/photo-puzzle.html`，通过 HTTP 本机打开；示例照片直接引用 https://picsum.photos/ 的固定随机 seed 图片（服务说明为 Unsplash 图片），不捆绑图片文件。随机示例不代表成都地点或真实到访。行政轮廓来自项目 `public/sichuan-cities.json` 中成都市，沿用地图数据来源声明。

- 单张：一个 SVG image，以 cover 裁切填满地区轮廓，没有平铺。
- 多张：扰动节点生成 3×2 / 4×3 的拓扑布局，共享随机凸凹 Bézier 边缘，每个共享边的逆向曲线完全相同；每块照片分别 cover，最外层按真实行政多边形 clipPath 裁切。
- 6 / 12 张切换、主动换拼法、放大 / 回到全貌、单块 hover 提亮可操作。相同 seed 在切换数量后布局稳定。
- 实际浏览器已验证 12 张远程照片加载、单张仅一个 image、多个拼块与外轮廓裁切、放大效果。临时截图 /tmp/travel-puzzle-preview/{six-photos,one-photo,twelve-zoom}.png。

后续：当前用扰动格点 + 凸凹边形成拼图，仍有基础行列结构。若选用该方向，可进一步探索 Voronoi 不规则拓扑与曲线边，确保每张照片有足够可见面积；增加主体裁切选择。真实接入只使用已确认并保存、与地区明确关联的照片；仅上传的草稿不自动成为旅行记录。城市边界覆盖、缩放层级、私有图片性能与导出需另行实现及验收。

## 日本多城市交互预览（2026-10-03）

新增 `docs/prototypes/japan-photo-puzzle.html`，本机 HTTP 预览：日本全图 → 点击城市 / 城市按钮 → 700ms 平滑放大并居中。聚焦范围按实际地图容器比例计算，保留完整城市边界和周围空间；快速切换取消上一段动画，减少动态效果偏好直接跳转。手机选城后滚动到地图。

- 札幌市 6 张、横浜市 1 张、京都市 12 张、大阪市 6 张随机公开示例。单张仅一个 image，不平铺；多张共享凸凹边并按城市轮廓裁切。
- 照片拼图开关控制所有城市，关闭显示地区底色，不改变当前视角。可以改变选中城市的照片数量、重新生成拼法、返回日本全图。
- 市级轮廓来自 [SmartNews japan-topography](https://github.com/smartnews-smri/japan-topography) 的 `data/municipality/geojson/s0010/N03-21_210101_designated_city.json`：国土交通省国土数値情報 2021 年行政区域数据，政令指定都市合并各区。嵌入四个城市的简化投影路径，保留来源声明。背景复用项目日本地图；此概览为四城市聚焦，未展示冲绳，不作为完整全国行政地图。
- 照片仍为 Lorem Picsum 随机外链，不是当地照片或真实到访。无私人照片文件、EXIF 或凭证，未写入私人数据仓库。

此版本仅为独立本机原型，尚未接入线上地图、真实已确认照片和导出。

验收：桌面实看札幌 / 横浜 / 京都及开关状态；横浜仅一个照片 image。390×844 手机实看大阪 6 张，选城后地图滚动到视口顶部，无横向溢出。`npm run typecheck` 和 `npm run build` 通过。

## 连续地图浏览与手动笔记（2026-10-03）

日本原型聚焦后仍可指针拖拽、滚轮以鼠标位置缩放、加减按钮缩放。拖拽超过 4px 抑制城市点击，开始操作即取消自动聚焦动画；同一城市重复点击不强制重置视角。手机可单指拖动并用加减按钮缩放；双指手势尚未实现。

照片笔记默认空，侧栏可选择照片并手动填写（仅内存，刷新清空，未写入私人数据）。只在拼图开启、非拖拽且地图 viewBox 宽度不超过 180 的细节层级显示非空笔记；缩小、离开照片、拖拽、关闭拼图立即隐藏。文本使用 textContent，空白笔记不显示，不自动生成叙事。正式接入仍须使用已保存记录中的用户笔记，以持久照片 ID 关联；原型使用城市与照片槽位，切换随机拼法不代表真实照片身份。

浏览器验证：横浜单张手动填写笔记，滚轮放大、拖动后悬停出现笔记，连续缩小后提示移除；原始城市选择和开关保留。类型检查与构建通过。
