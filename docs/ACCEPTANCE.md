# 讨论与计划总验收清单

## 层级导出更新

导出继承点击前地图地区，支持世界 / 亚洲、国家及已有轮廓的省市区县，并可回选祖先。三风格 / 三画幅共享地区筛选与真实边界照片裁切，144项测试覆盖同名歧义、缺失边界回退、范围隔离、署名与岛屿契约。浏览器本机验证日本市 / 中国区县、祖先选择、320 / 390 / 1280px与PNG生成状态；最终生产与设备证据见 [本轮验收](design/export-regions-2026-10-04.md)。旧“五种地域”是历史限制。

更新：2026-10-04。此清单是当前能力的统一入口；ROADMAP / PROGRESS / CONTEXT 中较早轮次描述是历史，不应把旧的“未接入”“等待 token”当作当前状态。实现、合成验收、正式域名复核、真机验收是不同证据。

**结论：核心私人旅行日志已实现并多轮发布；不是所有长期计划都开发、验收完成。** 本轮补齐导出样式收藏、旅行记录范围导出、照片读取预算 / 重试和文字编辑关闭保护。剩余事项按依赖与规模列在末尾，没有把它们勾成完成。

## 五轮打磨更新

已实现并合成验收：照片/管理/回收列表48项渐进呈现、时间线24项和月份筛选、共享分段键盘操作、登录密码核对、窄屏查看器工具、固定回收站头部、七个弹层与日本详细几何按需读取、公开资料去重/超时/失败重试。136项测试通过；当前发布证据见PROGRESS，[五轮报告](design/uiux-five-rounds-2026-10-04.md)区分构建体积、浏览器交互和真实设备/弱网未验收项。全库检索、100项选择上限、确认落点和owner合同保持；这不是服务端分页或完整容量验收。
