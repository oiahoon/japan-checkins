## 本轮用户目标

从日本扩展到四川，再到中国、世界。用户切换地理视图查看同一份日志，不为不同地图复制记录。把已保存足迹生成具有成就感的旅行地图，可分享、打印或作为壁纸。

本轮选择：直接延续已认可的界面，新增旅行地图切换栏和收藏入口。首版提供日本都道府县、中国省级、四川 21 市州边界 + 城市筛选、世界国家 / 地区概览。四川已绘制市州边界；小国 / 小岛可能未出现在世界低分辨率数据中。中国已补西沙物理小岛与局部放大框；后续继续提高地域覆盖，不以虚构点位填补。

导出首版：暖纸 / 绿灰地图、已到访地区着色、标题、次数、地区数量、日期范围。全部或按年筛选；A4、桌面、手机尺寸；PNG / SVG 下载、系统文件分享或下载回退、浏览器打印 / 存 PDF。默认不含精确坐标、照片、地点名称、笔记；精确落点由用户主动勾选。导出不改变记录公开权限，不生成未经授权的公开数据 URL。

## 数据与操作边界

country 是记录新增字段，旧记录默认 JP。中国使用 CN，省份继续保存在 prefecture，市州保存在 city。四川是 CN + 四川省 的视图，包含于中国和世界。所有记录沿用主人认证、私有仓库检查、幂等 ID 和有界 Git 冲突重试。

不迁移 / 修改原私人 Sites 资源、身份和访问权限。旧 Sites 适配器保留日本能力，多地区使用 GitHub / Next.js 运行时。照片、真实行程、原始 EXIF、凭证、个人 Site 标识不得进入公共代码 Git；QA 使用仓库外的合成数据。项目上下文、设计决策、来源、能力与计划放在本仓库 docs，不能把聊天记忆当作唯一交接。

### 多格式照片与相机信息（2026-10-03）

浏览器 exifr 解析 JPEG、HEIC/HEIF、TIFF 与 TIFF 类 RAW/DNG 的 EXIF；最大原图 100 MB，批量串行处理。品牌 / 型号 / 镜头 / 光圈 / 快门秒数 / ISO / 焦距通过白名单、长度和有限正数验证，保存到私有 GitHub 索引照片 metadata（可选字段，旧记录兼容）。主人读取 / 草稿恢复可取得 metadata，公开列表不输出。原图 EXIF 不写入 JPEG；GPS/日期只作待确认建议，不随相机字段保存。

HEIC 原生解码失败时动态加载 heic2any 本机转换；RAW 不做显影，只用可提取的内嵌 JPEG 预览，无预览明确拒绝上传并保留元数据建议。支持不代表所有 RAW 品牌容器、HDR HEIC 或相机机型已实测；真实 iPhone / GR / Q3 文件与移动浏览器验收尚待完成。该持久化适用于当前 GitHub 部署；历史 Sites/R2 路径未扩展相机字段。

## 手机上传反馈修正（2026-10-03）

用户明确：上传照片每张独立记录，分别读取 EXIF，不把整批合并；旅程合并留待后续。旧流程一批 6 张共用地图默认地区和同一日期，很容易造成误填。新流程批量选取 / 串行上传 → 第一张照片自动填入自己的待确认建议 → 核对保存 → 下一张；每次只关联一个 photo ID、保留独立幂等记录 ID，后续照片不沿用已保存照片的地点名称 / 日期 / 笔记。无日期建议留空；無 GPS 明确说明地图当前地区不是识别结果。用户必须确认地点、地区、实际日期，精确坐标仍另行确认；坐标与选定地区冲突时阻止保存。

主地图点击到访第一次聚焦，继续拖拽 / 缩放，再次点击才在侧栏内联展开照片 / 手填笔记，不切换时间线。保留完整时间线作为可选入口；历史多照片记录兼容并显示全部照片缩略图和区县字段。手机采用更高弹窗、64px 相册 / 相机按钮、固定保存区域和紧凑建议卡。

只读检查发现真实记录名称与地区不一致，原始照片 EXIF 已去除，不能从服务器 JPEG 副本重新获取各照片 GPS / 日期。真实旧记录没有自动拆分、改位置或迁移。用户重新选原图可读建议；旧记录修复需明确确认各照片归属。验收使用仓库外合成信息和临时内存适配器，临时接口 / 素材均已移除，不上线、不接触私人日志。
