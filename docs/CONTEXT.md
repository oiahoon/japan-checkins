# 项目上下文与产品方向

更新：2026-10-03。后续工作先读本文件、README、ARCHITECTURE、ROADMAP 和 PROGRESS；实现与验收以源码和当前证据为准。

## 已确定的产品

用户可以 clone 自行部署的旅行日志。公共代码仓库与部署者自己的私有 GitHub 数据仓库分开；GitHub 推送后由 Vercel 自动部署。保留 GitHub 存储，不接入 Supabase。默认私人密码访问，可配置只读密码、公开展示和 GitHub OAuth；公开内容必须逐条允许发布。

中文移动 UX，日式极简：暖纸、墨色、朱红主动作、照片优先、安静留白。拟物只用于控件的浅凹陷 / 轻凸起，避免整个页面厚重化。照片 → 确认地点 / 日期 → 保存 → 地图 / 时间线。EXIF 只提出建议，不推断到访历史、已吃过或探索深度。

## 本轮用户目标

从日本扩展到四川，再到中国、世界。用户切换地理视图查看同一份日志，不为不同地图复制记录。把已保存足迹生成具有成就感的旅行地图，可分享、打印或作为壁纸。

本轮选择：直接延续已认可的界面，新增旅行地图切换栏和收藏入口。首版提供日本都道府县、中国省级、四川 21 市州边界 + 城市筛选、世界国家 / 地区概览。四川已绘制市州边界；小国 / 小岛可能未出现在世界低分辨率数据中。中国已补西沙物理小岛与局部放大框；后续继续提高地域覆盖，不以虚构点位填补。

导出首版：暖纸 / 绿灰地图、已到访地区着色、标题、次数、地区数量、日期范围。全部或按年筛选；A4、桌面、手机尺寸；PNG / SVG 下载、系统文件分享或下载回退、浏览器打印 / 存 PDF。默认不含精确坐标、照片、地点名称、笔记；精确落点由用户主动勾选。导出不改变记录公开权限，不生成未经授权的公开数据 URL。

## 数据与操作边界

country 是记录新增字段，旧记录默认 JP。中国使用 CN，省份继续保存在 prefecture，市州保存在 city。四川是 CN + 四川省 的视图，包含于中国和世界。所有记录沿用主人认证、私有仓库检查、幂等 ID 和有界 Git 冲突重试。

不迁移 / 修改原私人 Sites 资源、身份和访问权限。旧 Sites 适配器保留日本能力，多地区使用 GitHub / Next.js 运行时。照片、真实行程、原始 EXIF、凭证、个人 Site 标识不得进入公共代码 Git；QA 使用仓库外的合成数据。项目上下文、设计决策、来源、能力与计划放在本仓库 docs，不能把聊天记忆当作唯一交接。

生产数据 token 由用户选择稍后配置：入口已部署，当前真实照片 / 记录写入仍不可用。不要宣称已验收实际私人 GitHub 写入。手机相机 / HEIC / 原生分享、实体打印与各浏览器仍需实际设备验证。无离线保存、自动拆分多地点照片或图片视觉定位。

## 拟物与地图细化（2026-10-03）

在用户认可的暖纸视觉上加强左上光源、轻凸按钮、凹陷输入和选中分段控件；朱红主动作保留颜色与焦点对比。高对比模式去除阴影，打印去除控件。四川 21 市州使用许可明确的真实几何，点击筛选；西沙用 Natural Earth 物理小岛补层和非同比例放大框，地图和导出一致。无虚构到访，无新增地理导航或官方审定承诺。
