## 当前能力

- 私有照片库：先上传，逐张补充地点 / 日期 / 笔记；地点关键词提供本地建议，选中后补齐所属地区，手动调整折叠显示。信息完整时点击“保存并标记地图”，缺项仍可保存照片信息；支持未标记 / 无笔记筛选。可配置服务端 Geoapify 在线提示，默认不开启。
- 旅行记录与照片双向管理：照片库按记录 / 未加入记录筛选；单张或批量新建 / 加入旅行相册，记录内反向选照片、移出关联，单张信息独立保存。相册最多 100 张；纯文字无需照片。新相册和文字记录暂仅私人查看，公开仍限原有逐条到访。
- 默认密码访问：管理密码可记录旅行，可选访问密码只读；GitHub OAuth 登录可选。
- 私有 / 公开模式可配置；公开页只展示主人明确发布的记录和照片，草稿及旧记录默认私有。
- 私有 GitHub 数据仓库：照片草稿、旅行记录、历史标记通过服务端 GitHub API 保存；仓库变为公开时拒绝访问。
- 照片缩小、客户端和服务端清除元数据；照片通过登录保护的接口读取，凭证不进入浏览器。
- 上传和保存幂等重试、Git 并发冲突有界重试，重复到访新增记录。
- 本机解析多格式 EXIF 地点 / 日期建议并私有暂存；确认或编辑后才标记地图。无 GPS 可手动输入或只记地区。
- 连续地理探索：平移跨地区保留视野，邻接轮廓可直接进入，分片到达后自然补充细节；世界 / 亚洲 / 国家，点击与缩放下钻日本 47 都道府县 / 1751 市区町村、中国 34 省级地区 / 四川 21 市州 / 成都 20 区县；地图内路径、返回、搜索和设备常用地区。西沙保留原位岛屿几何，导出保留局部放大框。侧栏按当前地区展示同一份日志。
- 旅行地图收藏：朱印与列岛 / 夜航图鉴 / 山河相册三种风格，全部或按年生成 A4 / 桌面 / 手机画幅；自定义标题、题记、字体、配色、地图缩放和拖拽位置，PNG / SVG 下载、系统分享或下载回退、打印 / PDF。默认简洁构图，统计 / 日期 / 地名可选；照片拼图和精确落点分别选择。
- 日本精选餐厅仍独立保留；任意城市 / 街道 / 地点可记录，地理与照片来源分开。

不支持离线保存或图片视觉定位；世界小国 / 小岛完整覆盖尚未实现。HEIC 在本机转换，RAW 需要可用内嵌预览（不做 RAW 显影），具体机型和真实手机兼容仍需实测。

布局与三种作品的实现、截图、验收范围见 [全站布局审阅](docs/design/layout-audit-2026-10-03.md)。

## Clone 与配置

```sh
git clone git@github.com:oiahoon/japan-checkins.git
cd japan-checkins
npm ci
npm run setup
# 按 docs/SELF-HOSTING.md 配置 .env.local
npm run dev
```

Node >=22.18。本地入口为 `http://localhost:3000`，绑定 loopback。setup 生成密码保存在本机 .setup/admin-password.txt；填写自己的私有仓库和受限 token 后使用。不会提供模拟登录或自动接入其他私人资源；缺少存储配置时显示提示并关闭上传和保存入口，地图仍可浏览。

完整 [密码访问、公开模式、私有仓库与 GitHub → Vercel 部署步骤](docs/SELF-HOSTING.md)。无需 D1、R2 或付费地理编码服务。建议公共代码仓库与自己的私有数据仓库分开；数据仓库也可以是你自己的私有项目副本。

```sh
npm run typecheck
npm test
npm run build
npm run start
```

默认运行 Next.js，提供 `vercel.json`；连接 GitHub 后 main 推送自动部署到 Vercel。GitHub Actions 校验源码、合成测试和构建，不处理个人照片或自动部署私人站点。每次保存直接写入数据仓库，无需等待构建。

## 验证与兼容

自动测试覆盖密码哈希、角色权限、公开投影、EXIF 缺失 / 损坏、边界、确认与元数据清除、会话签名 / 过期 / 所有权、并发记录及失败保存重试。真实私有仓库写入和手机照片上传需部署者使用自己的配置验收；不能把本地合成测试当作线上验收。

旧 Sites + D1/R2 适配器保留，可使用 `npm run dev:sites` / `build:sites` / `start:sites`。它只能在可信 Sites 网关下使用，不作为 Vercel 的认证路径。原私人 Site、数据和访问权限没有迁移或修改。迁移不会自动导入旧记录。

公共模板不包含照片、旅行历史、令牌或个人 Site ID。旅行与照片会留在数据仓库的 Git 历史中；移除草稿不会清除历史副本。地图和餐厅来源见 [数据说明](public/data-notes.md)。

项目上下文与方向见 [CONTEXT](docs/CONTEXT.md)，地理数据版本、许可、复现和导出规范见 [GEOGRAPHY](docs/GEOGRAPHY.md)。

### 2026-10-03 照片拼图体验上线

主人入口 `/photo-puzzle`：日本四城市随机照片拼图，开关、城市自动聚焦、连续拖拽 / 滚轮 / 按钮缩放、细节层级显示手动笔记。入口由服务端验证主人权限，沙箱 iframe 仅允许脚本；页面内示例不写入真实数据。笔记仅当前页面内存，刷新清空；随机照片不代表到访。这是独立体验原型；主地图真实照片拼图、手填笔记和导出已接入，见下方“主地图照片拼图模式”。此原型本身不保存笔记，不能用它代替真实功能验收。源原型在 docs/prototypes/japan-photo-puzzle.html，部署副本在 app/photo-puzzle/demo.ts，修改时同步。

照片导入支持 JPEG、HEIC/HEIF、TIFF 与可解析的 TIFF 类 RAW/DNG 元数据。HEIC 本机转换，RAW 仅提取可用内嵌预览（无预览需导出 JPEG），不做 RAW 显影。相机型号、镜头和曝光参数存入私有照片索引，GPS 和日期仍需确认。机型与移动设备实测状态见 docs/CONTEXT.md。

### 主地图照片拼图模式（2026-10-03）

已将照片拼图接入主地图工具栏和导出面板，开关默认关闭，导出面板默认继承地图选择并可独立切换。只使用已保存到访所关联的照片，草稿不进入拼图；没有照片的地区保留底色。日本按 2021 市区町村边界匹配明确城市名或已确认坐标（未知城市不扩大到都道府县）；四川按市州，中国按省级地区，世界按国家。照片在实际轮廓内 cover 裁切，单张不平铺，多张使用稳定随机凸凹边。主地图保留拖拽、按钮及滚轮缩放，拼图城市点击后聚焦；放大时只展示手填笔记。

导出照片先经已有认证接口读取并内嵌为 data URI，PNG / SVG / 分享 / 打印使用同一拼图。照片读取失败时阻止导出并给出提示；笔记和相机 metadata 不进入图像，精确落点仍是独立开关。分享前提示照片会包含在文件中。未新增公开照片接口或推断到访。日本城市边界来源和许可见 public/data-notes.md。

验收：合成测试验证草稿排除、城市匹配、单张非平铺、7 张拼块稳定布局、笔记转义及缩小隐藏、默认导出不含照片 / 开启内嵌照片。桌面浏览器验证主地图开关、导出继承与独立切换；手机检查控件布局。本机未配置私人存储，尚未用用户真实照片完成最终保存→拼图→导出验收。独立 `/photo-puzzle` 示例页保留作实验，已移除主页独立入口。

### 地区层级试点（2026-10-03）

旅行地图新增成都区县视图：可从中国 → 四川 → 成都区县导航，或直接选择成都；包含 20 个区、县、县级市。可把任意现有地图中的地区设为本机常用地区，刷新恢复；偏好只保存在浏览器，不代表到访或云端用户资料。成都保存复用 CN / 四川省 / 成都市，并添加 district 字段；旧记录兼容。照片拼图和导出按区县裁切，缺少区县和已确认坐标的历史照片不扩大填满成都。

区县数据为 geoBoundaries / OSM 的 2017 年范围参考，部分名称已对应现代显示名，不能作为现行行政、城市规划或导航图。全国省级选择已支持；全国市县名称与部分历史边界已扩展，现行边界补全、道路、地铁仍待后续。来源和验收见 [地区图层说明](docs/REGION-LAYERS.md)。

### 上传行为更新

批量选择照片后，**每张照片上传后直接存入私有照片记录，可稍后补充；确认地点和日期后分别保存为一条到访**，不会共用整批的地点和日期。第一张保存后继续确认下一张；没有 EXIF 地点 / 日期请手填，不以默认地图地区或今天代替识别结果。旅程合并暂未提供。地图上的记录首次点击聚焦，再次点击在侧栏展开，不离开地图。已有多照片记录保持原样。

### 照片查看与管理

时间线、记录内照片和上传预览使用站内查看器：前后切换、缩放、手机滑动与键盘方向键，关闭后留在原页面。GitHub 主人可将已保存照片移入回收站，并从工具栏回收站恢复；到访记录和 Git 历史保留，不是永久擦除。查看器的「重新上传原图」打开逐张确认流程，读取原图 EXIF 后新增独立到访，不自动覆盖旧照片或旧记录。请先核对新记录，再把旧照片移入回收站。只读 / 公开访客没有管理入口。

手机地图优先展示地图；“地图选项”展开拼图、收藏与其他设置。底部地区抽屉可查看到访，选择后自动收起并聚焦地图，再通过“查看记录”打开详情。地图导出为全屏预览，点“调整地图”修改标题、时间、画幅；详情和导出均可关闭返回原视图。

主人可在“地图选项 → 管理记录与照片”或时间线“批量管理”中多选 / 全选记录或已保存照片，每批最多 100 项，经确认移入回收站或恢复。详情“删除这条记录”会预选该记录。删除记录会隐藏关联照片、落点、时间线与导出统计；单独删除照片保留记录。回收站可批量恢复，单独删除的照片不会因记录恢复而自动恢复。历史标记仍保留，恢复沿用原公开设置。仅支持 GitHub 模式，文件和 Git 历史未永久清除。

### 照片记录与导出风格

「照片」页展示已保存的国家、地区、城市、地点、日期、笔记和缺失信息；只填地区也会显示，不要求先确认地图标记。信息保存与地图标记的状态分别提示；可用「未标记」「无笔记」组合筛选。点击照片补充信息，缺项也能保存，只有确认后的完整记录进入旅行地图。精确坐标与相机信息收在「查看更多」，规范化 EXIF 建议私有保存以便刷新后继续整理。修改已公开照片记录后撤回公开状态，需要再次允许展示。

导出提供旅行书页、夜色收藏、照片纪念三种风格，支持日本 / 四川以及其他已有地图；可调整标题、题记、地图大小（50–160%）、拖拽位置和 A4 / 桌面 / 手机画幅，可在预览上拖动地图、用方向键微调；“居中”只重置位置，“恢复默认”同时重置大小与位置。地图与照片同步变换，文案保持独立；超出地图画幅的部分裁切。拼图和精确落点仍由用户独立控制。照片纪念默认开启拼图，仅使用已确认到访关联的照片。

照片信息编辑：先填写地点，已知城市 / 区县会补出所属国家与地区；重名需选择，未知地点可手动调整。拍摄日期优先从 EXIF 读取，数字化日期仅作待核对建议；无日期时可在“查看更多”选择原图本地补读。定位与日期始终需确认后才标记地图。

### 国内市县扩展（2026-10-03）

名称目录补至 34 个省级地区、393 个市州 / 直辖单位、3336 个区县等下级地名；直辖市、省直辖县、台湾、香港和澳门按各自层级整理，同名地名保留完整父级。主地图可搜索 / 下钻，照片编辑提供省 → 市 → 区县联动，保存 / 刷新保留 district。边界按省懒加载，新增公开参考资产含 382 个市级等轮廓和 2663 个下级轮廓；缺失区域回退上一级。名称为内地 2023 / 台湾 2021 快照，几何多为 2017 / 2020，不能称为 2026 全量现行行政图。完整来源、许可、逐省覆盖和重建命令见 [国内覆盖说明](docs/CHINA-COVERAGE.md)。
